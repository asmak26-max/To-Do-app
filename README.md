# To-Do-app

📝 To-Do List Application

A simple C++ command-line To-Do List application developed as a learning project.

🎯 Purpose

This project demonstrates basic C++ programming concepts through a small task-management application.

Features

- Add tasks
- View tasks
- Mark tasks as completed
- Menu-driven command-line interface

🛠️ Technologies

- C++
- STL
- "struct"
- "vector"
- Loops
- Conditional statements
- Basic file-handling concepts


📚 Learning Focus

The project was created to practice:

"C++ Basics → Data Structures → Control Flow → Functions → File Handling"
